# Goose Patrol (ENG1 Team 2)

`main` holds the team's own work: the libGDX project set-up, the campus map and collisions,
the hidden event classes, Req1, the meeting notes, the website, and the sprites and sounds.

The earlier full version, much of which was written with a generative AI assistant, is kept
unchanged on the branch `archive/ai-assisted-draft` for reference. The module only allows
generative AI for graphics, sounds and the website, so the code and the reports are being
rewritten by the team on `main`.

Build and run: `./gradlew lwjgl3:run` (Java 17).

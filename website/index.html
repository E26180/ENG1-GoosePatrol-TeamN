Goose Patrol

Waves of hungry geese are coming across the University of York campus. Feed them until they fly away, and clear every wave before the 5-minute timer runs out. No geese are harmed.

The game

  • A 5-minute countdown timer that is always on screen, with a pause option
  • Waves of geese to feed and send on their way
  • A map based on the University of York campus
  • Two items in your inventory at the start
  • Two hidden events waiting to be found
  • Counters for the items you use and the events you trigger

Built in Java 17 with LibGDX.

Play the game

Download GoosePatrol-1.0.0.jar (about 17 MB). It runs on Windows, macOS and Linux with Java 17 or newer and a graphics driver with OpenGL.

  • Try double-clicking the JAR. This works only if your computer opens .jar files with Java 17 or newer.
  • If double-clicking does nothing, or opens another program, open a terminal in the download folder and run java -jar GoosePatrol-1.0.0.jar. If that fails, java -version shows which Java the terminal uses; it must be 17 or newer.
  • No Java yet? Install a Java 17 runtime, for example Eclipse Temurin 17.

Earlier builds were played on macOS, Ubuntu Linux and a Windows PC. Each test names the exact build it used: see the platform test notes and the player test plan.

How to play: three waves of hungry geese come to Campus East. Click a goose with the Bag of Oats (key 1), or throw Bread (key 2) near a group. A full goose flies away happily. Feed every goose before the 5 minutes run out. A goose that flashes red and honks wants your snack, so step away or feed it. Odd things are hidden around campus, such as a lost backpack and a tall duck staring at a bucket: walk up to them to see what they do. Tips appear while you play (T hides them).

Controls: WASD or arrow keys to walk, 1–9 to choose an item, left click to use it, P or Esc to pause, M for sound on or off, T for tips on or off, R to play again after a game.

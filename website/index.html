Play the game

Download GoosePatrol-1.0.0.jar. It runs on Windows, macOS and Linux with Java 17 or newer.

  • Try double-clicking the JAR. This works only if your computer opens .jar files with Java 17 or newer.
  • Otherwise open a terminal in the download folder and run java -jar GoosePatrol-1.0.0.jar. java -version shows which Java the terminal uses.
  • No Java yet? Install a Java 17 runtime, for example Eclipse Temurin 17.

What the game does so far, and what is not finished yet, is listed in Impl1.pdf.

This build is made automatically from the code on main.

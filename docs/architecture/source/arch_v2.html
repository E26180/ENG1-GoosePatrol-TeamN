What changed from v1 to v2, and how the components map to the code

v1 was the team's first draft (kept in docs/architecture/ so the report can show how the design evolved). Changes, with the requirement IDs from Req1:

  • Player health and damage removed. The game has no violence (UR_NONVIOLENT, QR_NO_HARM) and is only lost when the timer runs out (FR_JUDGEMENT); geese block the player instead of hurting them (UR_BOUNDS).
  • Pause added (UR_PAUSE): the game starts paused and the pause key stops timer and game (FR_START_PAUSED, FR_PAUSE_KEY).
  • Counter System added (UR_COUNTERS, needed in Assessment 1: items used, events triggered). The Score System is Assessment 2 only and is dashed.
  • Hidden Event System replaces the notification-style "Event System": hidden events are triggered when the player is near them (FR_EVENTS, FR_EVENT_EFFECT).
  • Feeding link added from Inventory System to Enemy System through the interfaces Feedable and GooseLocator (FR_SINGLE_TARGET, FR_MULTI_TARGET).
  • Collectible System (pick-up items on the map) is marked Assessment 2 (UR_MAP_ITEMS, A1 = No).
  • Component names now match the packages and classes in the code; typos fixed.

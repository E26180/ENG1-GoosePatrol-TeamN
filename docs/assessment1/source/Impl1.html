Implementation – Part b

The code is in the team repository and the playable JAR is on the team website. Every public class and method is documented with Javadoc (QR_DOCUMENTATION), and the logic that does not need a window is covered by 106 JUnit tests, which the website build runs before it publishes the JAR.

Suitability. Every licence allows use in a free university game and allows us to change the art. The permissive licences (Apache, BSD, EPL, OFL) ask that their notices go with the game: THIRD-PARTY-NOTICES.txt inside the JAR does this, and assets/CREDITS.md lists every asset file (QR_LICENSING). The two LGPL libraries are used unchanged, and the game can be rebuilt from our repository against another version of them, as the LGPL requires. Tiled’s GPL covers only the editor, not the maps made with it. The one condition that limits us is Cozy World’s ban on sharing its tiles as a pack, so the repository and JAR keep only the tiles the map uses, inside the game. No licence asks for a credit in the game; the packs are credited on the website.

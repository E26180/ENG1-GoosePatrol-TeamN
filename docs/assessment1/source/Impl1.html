The code is in the team repository and the playable JAR is on the team website. The code is documented with Javadoc (QR_DOCUMENTATION), and the logic that does not need a window (items, inventory, player movement, timer, game rules, hidden-event triggering) is covered by JUnit tests (./gradlew test).

Implementation – Part b

The code is in the team repository and the playable JAR is on the team website. Every public class and method is documented with Javadoc (QR_DOCUMENTATION), and the logic that does not need a window is covered by 118 JUnit tests, which the website build runs before it publishes the JAR.

Suitability. Every licence allows use in a free university game and changes to the art. The permissive licences (Apache, BSD, zlib, MIT, OFL) ask that the copyright notice and licence text go with the game: the JAR holds THIRD-PARTY-NOTICES.txt and the full texts in licenses/; assets/CREDITS.md lists every asset file (QR_LICENSING). The LGPL parts (JLayer, JOrbis and LWJGL’s OpenAL Soft) are unchanged and replaceable, as the LGPL requires; the notices file says how. Tiled’s GPL covers only the editor, not its maps. Only Cozy World limits us: its tiles may not be shared as a pack, so we keep just the tiles the map uses, inside the game. No licence needs an in-game credit.

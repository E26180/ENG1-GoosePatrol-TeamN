Goose Patrol - third-party software and assets
==============================================

This game (ENG1 Team 2, University of York) includes the following third-party
software and assets. Each is used under the licence named. The full text of every
software licence is in the licenses/ folder next to this file (inside the JAR, and in
assets/licenses in the repository). The game's own code, sprites and sound effects are
the team's own work.

Software (inside GoosePatrol-1.0.0.jar)
---------------------------------------
libGDX 1.14.2 (gdx, gdx-backend-lwjgl3, gdx-platform, gdx-jnigen-loader 2.5.2)
  Copyright 2011 the libGDX authors (see the AUTHORS file in the source)
  Apache License 2.0 - licenses/Apache-2.0.txt
  Source: https://github.com/libgdx/libgdx

LWJGL 3.4.3 (lwjgl, glfw, opengl, openal, stb, jemalloc)
  Copyright (c) 2012-present Lightweight Java Game Library
  BSD 3-Clause licence - licenses/LWJGL-BSD-3-Clause.txt
  LWJGL ships native libraries for each system (the .dll, .dylib and .so files in the JAR):
    GLFW         zlib licence             - licenses/GLFW-zlib.txt
    jemalloc     BSD 2-Clause licence     - licenses/jemalloc-BSD-2-Clause.txt
    stb          MIT or public domain     - licenses/stb-MIT-or-Unlicense.txt
    OpenAL Soft  GNU Library GPL v2       - licenses/LGPL-2.0.txt
                 Source: https://github.com/kcat/openal-soft
                 OpenAL Soft is a separate library loaded when the game starts. It is used
                 unmodified and can be replaced with another build by starting the game with
                 java -Dorg.lwjgl.openal.libname=<path to the library> -jar GoosePatrol-1.0.0.jar

JLayer 1.0.1-gdx (MP3 decoding, included by the libGDX desktop backend)
  GNU Library General Public License, version 2 or later - licenses/LGPL-2.0.txt
  (version 2.1 also in licenses/LGPL-2.1.txt)
  Source: https://github.com/libgdx/jlayer

JOrbis 0.0.17 (Ogg Vorbis decoding, included by the libGDX desktop backend)
  GNU Library General Public License, version 2 or later - licenses/LGPL-2.0.txt
  Source: http://www.jcraft.com/jorbis/

  Both libraries are used unmodified; the game itself plays only WAV files. To use a
  modified version, either replace their classes in the JAR (javazoom/ and com/jcraft/;
  a JAR is an ordinary zip file), or rebuild the game from its source and build files in
  the team repository with the other version: https://github.com/E26180/ENG1-GoosePatrol-TeamN
